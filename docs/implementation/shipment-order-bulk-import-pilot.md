# 출하주문 대량 엑셀 등록 파일럿

## 목적

`shipment-order-status` 동적 메뉴에서 1,000~20,000행 엑셀을 검증하고 등록하는 파일럿 기능이다. 행마다 서버를 호출하지 않고 주문 그룹 단위 청크로 처리하며, 화면에서 검증·등록 진행률과 오류 내용을 확인할 수 있다.

## 사용 방법

1. 백엔드를 재시작하고 프론트엔드 화면을 새로 고친다.
2. `shipment-order-status` 메뉴에서 **대량 엑셀 등록** 버튼을 누른다.
3. B2C 또는 B2B 업무 유형과 엑셀 파일을 선택한다.
4. **검증**을 실행해 오류가 0건인지 확인한다.
5. **등록**을 실행하고 진행률과 완료 건수를 확인한다.

백엔드 시작 시 해당 라우트를 사용하는 각 도메인의 메뉴에 버튼과 다국어 용어가 없을 때만 자동으로 등록된다.

## 정확성 보호

- 전체 파일을 먼저 검증하며 오류가 한 건이라도 있으면 등록 버튼이 활성화되지 않는다.
- 등록 청크마다 서버에서 동일 검증을 다시 수행한다.
- 같은 `ref_order_no`의 행은 하나의 청크에서 처리한다.
- 기존 주문번호, 화주사, 창고, SKU, B2B 거래처, 날짜, 수량, 중복 라인과 주문 헤더 일관성을 검사한다.
- 모든 업무 조회는 현재 `domain_id` 범위에서 수행한다.

## 처리 단위와 제한

- 파일 최대 크기: 20,000행
- 처리 단위: 기본 200행, 화면에서 20~2,000행 사이로 변경 가능
- 동일한 참조 주문번호의 행은 처리 단위보다 크더라도 분리하지 않음
- 검증과 등록 진행 중 경과 시간을 `mm:ss` 형식으로 표시
- 현재 파일럿은 브라우저가 청크를 순차 호출하는 Java 기반 구조다.
- 등록 도중 후속 청크가 실패하면 이전에 완료된 청크는 유지된다. 재시도 시 기존 주문번호 중복 검증이 중복 등록을 막는다.
- 서버 비동기 작업 큐와 스테이징 테이블을 사용하는 완전한 하이브리드 구조는 파일럿 측정 후 다음 단계로 확장한다.
