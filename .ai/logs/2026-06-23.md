## 10:00 — 재고 부족 대응: B2C 포장 화면 결품 처리 UI 추가 (N-5)

### 작업 내용
- `fulfillment-b2c-packing-pc.js`에 포장 작업 중 재고 부족 아이템을 포장 작업자가 직접 결품 처리할 수 있는 UI 구현
- 결품 처리 버튼 클릭 → 확인 다이얼로그 → `POST /rest/ful_trx/packing_orders/{id}/items/{itemId}/short` API 호출
- SHORT 상태 아이템은 검수 완료 항목으로 카운트하되 출하 차단됨을 UI에서 명시

### 변경/생성 파일
- `frontend/packages/operato-wes/client/pages/fulfillment/fulfillment-b2c-packing-pc.js` — 결품 처리 UI 추가: shortDialogOpen/shortDialogItem 프로퍼티, .row-short/.badge-short/.btn-short CSS, _onShortItem()/_closeShortDialog()/_confirmShortItem() 메서드, 결품 확인 다이얼로그

### 주요 결정 또는 발견 사항
- SHORT 아이템은 `completedCount`에 포함 (더 이상 포장 동작 불필요)하여 전체 완료 체크를 블록하지 않도록 처리
- `_onSkuSelect()`, `_moveToNextItem()`에서 `status !== 'SHORT'` 조건 추가하여 SHORT 아이템을 건너뜀
- 완료 패널 컬러를 SHORT 있을 때 오렌지/경고색으로 전환하여 "출하 차단" 상태를 시각적으로 구분
- 피킹 시 pick_qty=0으로 생성된 SHORT 아이템도 뱃지와 취소선으로 표시
