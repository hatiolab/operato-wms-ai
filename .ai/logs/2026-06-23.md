## 20:30 — DB 연결 keepalive 설정 (ECONNRESET 방지)

### 작업 내용
- 프론트엔드 개발 서버가 가끔 `ECONNRESET` 오류로 접속 불가해지는 원인 진단
- Termius SSH 포트 포워드(localhost:15432) 유휴 타임아웃으로 DB TCP 연결이 강제 종료됨이 원인
- TypeORM `extra.keepAlive: true` 설정으로 TCP keepalive 활성화

### 변경/생성 파일
- `frontend/packages/operato-wes/config/config.development.js` — `ormconfig.extra.keepAlive: true`, `keepAliveInitialDelayMillis: 30000` 추가

### 주요 결정 또는 발견 사항
- `lsof -i :15432` 결과 모든 연결이 CLOSED 상태 → 터널 단절 확인
- 근본 해결: Termius 호스트 설정에서 SSH keepalive 60초 간격 활성화 권장
- `extra.keepAlive`는 `pg` 드라이버 레벨 TCP keepalive — 30초마다 패킷 전송으로 유휴 단절 방지
