## 14:00 — B2C StockAllocation SOFT/HARD 상태 전환 구현

### 작업 내용
- B2C 주문만 재고 할당 시 SOFT 상태로 생성하고, 웨이브 릴리즈 시 HARD로 전환하는 로직 구현
- B2B 및 VAS는 기존대로 HARD로 직접 생성

### 변경/생성 파일
- `src/main/java/operato/wms/stock/service/StockTransactionService.java` — `allocateInventory()` 오버로드 추가 (status 파라미터 버전); 기존 메서드는 HARD를 전달하는 위임 형태로 변경
- `src/main/java/operato/wms/oms/service/OmsShipmentOrderService.java` — 할당 시 `bizType.startsWith("B2C")` 이면 STATUS_SOFT, 그렇지 않으면 STATUS_HARD 전달
- `src/main/java/operato/wms/oms/service/OmsWaveService.java` — `releaseWave()`: 주문 RELEASED 처리 후 B2C SOFT→HARD 일괄 전환 SQL 추가; `cancelWaveRelease()`: 주문 WAVED 복원 후 B2C HARD→SOFT 일괄 복원 SQL 추가

### 주요 결정 또는 발견 사항
- B2C bizType 판별: `biz_type LIKE 'B2C%'` (B2C_OUT, B2C_RTN 모두 포함)
- SOFT→HARD/HARD→SOFT 전환은 `stock_allocations` 테이블 직접 UPDATE (서브쿼리로 해당 웨이브의 B2C 주문 대상 한정)
- `cancelWaveRelease()`에서도 HARD→SOFT 복원 처리하여 일관성 유지
