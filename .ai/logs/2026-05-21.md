# 2026-05-21 작업 로그

## 09:00 — Jasper PDF 인쇄 오류 원인 분석 및 수정

### 작업 내용
- 로컬에서는 정상 동작하지만 AWS Docker 배포 환경에서 PDF 인쇄가 안 되는 문제 조사
- `processStreamRest` 에러 핸들러의 null 미체크 및 스트림 미소비 버그 수정
- 근본 원인 확인: `ghostPrintPdf`가 서버 URL을 iframe `src`에 직접 전달하여 브라우저 GET 요청을 발생시키지만 백엔드 엔드포인트는 POST 전용이라 405 오류
- `ghostPrintPdf`를 `operatoPost` + Blob URL 패턴으로 재작성 (`basic-pdf-print.js` 참조)

### 변경/생성 파일
- `frontend/packages/operatofill/server/middlewares/index.ts` — `processStreamRest` catch 블록 null-safe 처리 및 스트림 에러 본문 읽기 로직 추가
- `frontend/packages/metapage/client/utils/print-util.js` — `ghostPrintPdf` POST + Blob URL 방식으로 재작성, 미사용 `operatoGet` import 제거

### 주요 결정 또는 발견 사항
- `GhostPrint.print({src})` 는 내부적으로 `<iframe src=...>` 를 생성하여 브라우저 GET 요청을 발생시킴 — 직접 서버 URL 전달 불가
- 올바른 패턴: POST로 PDF 바이트 수신 → `Blob` 생성 → `URL.createObjectURL` → GhostPrint에 blob URL 전달
- `parameters`(선택된 행 데이터)가 기존에는 완전히 무시되고 있었음 — 수정 후 백엔드에 실제 전달
