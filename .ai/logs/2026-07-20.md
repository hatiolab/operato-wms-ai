## 10:00 — code_select select_label_key 기반 xlsx 드롭다운 + import 역변환 설계 및 구현

### 작업 내용
- `select_label_key`를 재활용하여 xlsx 드롭다운 표시값과 임포트 전송값을 분리하는 구조 설계
  - `select_value_key=name`: 임포트 시 실제 전송값 (코드)
  - `select_label_key=description`: xlsx 드롭다운 표시값 (설명)
- `import_ref_col` 신규 필드 추가 — 참조 컬럼의 원본 셀값(역변환 전)을 이 컬럼 값으로 사용
- DB 마이그레이션, Java 엔티티, 백엔드 서비스, 프론트엔드 전체 반영

### 변경/생성 파일
- DB: `excel_template_columns.import_ref_col VARCHAR(100)` 컬럼 추가
- `otarepo-core/src/main/java/xyz/elidom/dev/entity/ExcelTemplateColumn.java` — `importRefCol` 필드 + getter/setter 추가
- `otarepo-core/src/main/java/xyz/elidom/dev/service/ExcelTemplateService.java` — `select_label_key` 우선으로 xlsx 드롭다운 표시 변경
- `frontend/packages/metapage/client/pages/excel-template-detail.js` — 확장 행에 **참조 컬럼** 입력 필드 추가 (4열 → 5열 그리드)
- `frontend/packages/metapage/client/pages/dynamic-excel-import-popup.js` — `_codeSelectMaps` property 추가, `_fetchCodeSelectMaps` 메서드 추가, `_buildImportBody` 역변환·참조 처리 구현

### 주요 결정 또는 발견 사항
- **select_label_key 재활용**: `api_select`와 동일한 의미론(value_key=실제값, label_key=표시값)을 `code_select`에도 적용 — 새 필드 불필요
- **처리 순서**: `_buildImportBody`에서 원본 셀값 스냅샷(`originalValues`) 먼저 캡처 후 역변환 처리 → `import_ref_col`이 항상 역변환 전 원본값 참조 가능
- **2단계 API 조회**: `common_codes`(그룹 id 조회) → `common_code_details`(상세 목록 조회) 순으로 역변환 맵 구성
- **설정 예시**:
  ```
  reason_cd: code_select, select_source=INV_NEW_REASON, select_value_key=name, select_label_key=description
  reason:    template_skip=true, import_skip=false, import_ref_col=reason_cd
  ```
