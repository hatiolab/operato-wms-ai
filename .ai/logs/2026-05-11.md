## 16:00 — PDA 재고 이동 화면 From 로케이션 추가 및 UX 개선

### 작업 내용
- `pda-stock-move.js`에 From 로케이션 입력 필드 추가
- Inventory의 (domainId, locCd, barcode) 복합 유니크 제약으로 인해 From 로케이션 없이는 이동 대상 재고를 정확히 특정할 수 없는 문제 해결
- 스캔 순서 및 포커스 동작을 작업 흐름에 맞게 재설계

### 변경/생성 파일
- `frontend/packages/operato-wes/client/pages/pda/pda-stock-move.js` — From 로케이션 필드 추가, 스캔 순서·포커스 동작 전면 수정

### 주요 결정 또는 발견 사항
- **스캔 순서**: To 로케이션(1회 확정) → From 로케이션 → 바코드 → (반복)
- **바코드 성공 시**: From 로케이션 + 바코드 초기화 → From 포커스 (다음 로케이션으로 이동 가능)
- **바코드 실패 시**: 바코드만 초기화 → 바코드 포커스 유지 (같은 From에서 재스캔)
- `validate_barcode_for_move` API 호출에 `from_loc_cd` 파라미터 추가
- `_confirmMove`에서 각 항목의 `from_loc_cd`는 `inv.loc_cd` 사용 (여러 From 로케이션 혼합 지원)
- To 로케이션 `변경` 시 From + 스캔 목록 전체 초기화

## 17:00 — PDA 재고 조회 화면 바코드·검색 조건 UX 개선

### 작업 내용
- `pda-stock-inquiry.js`의 검색 입력 박스 3개에 대해 스캔 결과가 없을 때 자동 리셋 처리 추가
- '초기화' 버튼 클릭 시 state뿐 아니라 `ox-input-barcode` DOM 값도 직접 클리어

### 변경/생성 파일
- `frontend/packages/operato-wes/client/pages/pda/pda-stock-inquiry.js` — 바코드·로케이션·상품코드 입력박스 결과 없음 리셋, 초기화 버튼 DOM 클리어 추가

### 주요 결정 또는 발견 사항
- `ox-input-barcode`는 내부 상태를 독립적으로 관리하므로 state 초기화만으로는 UI 값이 안 지워짐 → DOM에 직접 `.value = ''` 필요
- 각 입력 핸들러를 인라인 → `_onBarcodeChange`, `_onLocCdChange`, `_onSkuCdChange` 메서드로 분리
- 입력 박스에 id 부여(`#barcodeInput`, `#locCdInput`, `#skuCdInput`)하여 `shadowRoot.querySelector`로 접근

## 20:00 — PDA 재고 조회 화면 재고 이동 기능 추가

### 작업 내용
- `pda-stock-inquiry.js` 상세 화면에 '이동' 버튼 추가
- 재고 이동 전용 모드(`move`) 및 화면 구현: To 로케이션 · 이동 수량 · 이동 사유 입력
- To 로케이션 입력 시 `inventory_trx/validate_location_for_move` API로 유효성 검증
- `inventory_trx/{id}/move_inventory` API 호출 (기존 API가 `to_qty` 지원으로 부분 이동 가능)
- To 로케이션 `ox-input-barcode`가 너무 짧은 문제 수정 (`.form-field ox-input-barcode { flex: 1 }` 추가)

### 변경/생성 파일
- `frontend/packages/operato-wes/client/pages/pda/pda-stock-inquiry.js` — move 모드 상태·렌더링·메서드 추가, form-field CSS 보완

### 주요 결정 또는 발견 사항
- `StockTransactionService.moveInventory(Long, InvTransaction)`가 이미 `to_qty` 처리 → 별도 API 추가 불필요
- 이동 수량 기본값: 가용 수량(`inv_qty - reserved_qty`)으로 자동 설정 (전체 이동이 기본)

- detail 모드 footer를 4버튼(`이력·이동·조정·메인`) + `compact` 스타일로 변경
